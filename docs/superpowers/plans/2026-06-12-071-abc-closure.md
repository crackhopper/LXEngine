# REQ-071 A/B/C Closure Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close the main code gaps in REQ-071-a/b/c so the default validation path is Material v2 strict, RenderPathGraph-driven, and backed by SceneResourceTable typed resources.

**Architecture:** Keep Material v2 as the only material parameter truth, RenderPathGraph as the only pass/source/target/shader truth, and SceneResourceTable as the owner of resource identity and typed payloads. Parallel work is split by ownership: validation profile parsing, renderer graph pass ownership, and resource-table shader dependency ownership.

**Tech Stack:** C++20, CMake/Ninja, YAML parsers in `src/infra`, core render/resource contracts in `src/core`, Vulkan realtime integration in `src/backend/vulkan`.
