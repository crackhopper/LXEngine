## PLY 的两种身份

PLY 是一个可扩展容器，不等于 mesh。普通 mesh PLY 用 vertex + face 表达三角表面；3D Gaussian Splatting 使用 PLY 的 `vertex` element 存每个 Gaussian 的参数。

| 属性族 | 普通 mesh PLY | 3DGS PLY |
|---|---|---|
| 几何 | `x/y/z` + face index | `x/y/z` 是 Gaussian center |
| 法线 | 表面 normal | `nx/ny/nz` 常是兼容占位，不定义形状 |
| 颜色 | RGB / material | `f_dc_*` + `f_rest_*` 球谐系数 |
| 形状 | triangle | `scale_*` + `rot_*` 定义椭球协方差 |
| 透明 | material alpha | `opacity` 每 splat 存储 |

PlayCanvas 的 PLY 格式文档把 `scale_0..2`、`rot_0..3`、`opacity`、`f_dc_0..2`、`f_rest_0..44` 作为 3DGS PLY 的核心字段；Kaolin 的 import/export API 也采用同一字段族。

## Loader 的格式判断

`GaussianSplatPlyLoader` 不应该只看扩展名。它需要读取 header 并验证必要属性：

| Header 条件 | 处理 |
|---|---|
| `format binary_little_endian 1.0` | 首版唯一支持 |
| `element vertex N` | 记录 splat count |
| `property float x/y/z` | 必须存在 |
| `property float f_dc_0..2` | 必须存在 |
| `property float opacity` | 必须存在 |
| `property float scale_0..2` | 必须存在 |
| `property float rot_0..3` | 必须存在 |
| `property float f_rest_0..44` | 可选但应保留 |

属性顺序不应硬编码。GraphDeco 风格文件通常顺序固定，但 PLY 允许自定义属性顺序；loader 需要通过 header 建立 offset 映射。
