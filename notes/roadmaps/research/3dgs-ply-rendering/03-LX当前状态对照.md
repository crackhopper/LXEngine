# 03. LXEngine 当前状态对照

> 状态：已立项
> 调研日期：2026-05-28
> 对应需求：`REQ-077-a`、`REQ-077-b`、finished `REQ-063-a`

## 当前资产与 scene 表面

当前 scene 文档已经能保存 camera、light、mesh URI、material URI、transform 和 editor camera。仓库没有 in-git `3dgs_train_sample.scene.yaml` 或大型 PLY；assets-downloader 只提供 point-cloud cache manifest 和 `sceneUsage.gaussianSplatUri`。

即使手写 `.ply` URI，运行时也不会渲染它：`SceneRuntime` 只识别 builtin mesh、builtin model、OBJ、glTF。未知 URI 最终会落到空 `SceneNode` 或错误路径。

| 当前事实 | 对 3DGS 的影响 |
|---|---|
| `SceneNodeDocument` 只有 `meshUri` / `materialUri` | 需要新增 `gaussianSplat.uri` canonical 表面 |
| `loadModelMesh()` 只支持 `.obj`、`.gltf`、`.glb` | 不能把 `.ply` 塞进 mesh loader |
| `Mesh` 绑定 `VertexBuffer` + `IndexBuffer` | 3DGS 需要独立 buffer layout |
| material 依赖 shader reflection | 3DGS 首版 shader 可以独立于 material system |
| FrameGraph / render loop 已有 forward + overlay 路径 | 3DGS pass 应作为独立透明 pass 插入 |

## 应复用的部分

| 现有部分 | 复用方式 |
|---|---|
| asset path helper / cache URI resolver | 定位 assets-downloader cache PLY |
| scene transform | 作用到 splat cloud local-to-world |
| camera component | 提供 view/projection 和 culling mask |
| editor scene tree | 显示节点，后续加类型摘要 |
| Vulkan buffer RAII | 上传 splat data / indices |
| notes / requirements 流程 | 分阶段验收 |

## 不应复用的部分

| 不复用对象 | 原因 |
|---|---|
| `ObjLoader` / `GLTFLoader` | 它们产出 triangle mesh 语义 |
| `Mesh` | 3DGS 没有 index buffer 和 triangle bounds 语义 |
| 普通 material pass | 首版 3DGS shader 需要专用 blend / footprint 逻辑 |
| shadow pass | splat shadow 不是当前首版目标 |
