# 04. LXEngine 3DGS PLY 演进路径

> 状态：已立项
> 调研日期：2026-05-28
> 对应需求：finished `REQ-060-a` / finished `REQ-063-a`，active `REQ-077-a` 到 `REQ-077-e`

## 分阶段原则

3DGS PLY 支持必须切成连续实施周期。原因有三点：

1. 文件格式和资源语义先于渲染。
2. runtime scene node 必须先能稳定持有 splat cloud。
3. Vulkan pass 涉及透明排序和专用 shader，风险高于普通 mesh loader。

## REQ 拆分

| REQ | 阶段 | 为什么独立 |
|---|---|---|
| finished `REQ-060-a` | 资产预算与 PLY 样例策略 | 旧 in-git 大型 PLY 策略已废弃，资产改走 assets-downloader cache |
| `REQ-077-a` | PLY loader 与 CPU resource | 独立验证文件格式和数据解释 |
| `REQ-077-b` | runtime resource 与 scene node | 独立验证 scene 能持有 splat，不依赖 Vulkan |
| finished `REQ-063-a` | Compute pipeline foundation | 3DGS GPU projection / sort / composite 前的通用 compute 能力 |
| `REQ-077-c` | Vulkan splat pass | 集中处理 3DGS GPU buffer、排序、shader 和 blending |
| `REQ-077-d` | editor scene validation | 用固定 scene 和命令/API 做可重复验收 |
| `REQ-077-e` | system design and tutorial | 功能闭环后沉淀教程和设计说明 |

## 首版边界

| 做 | 不做 |
|---|---|
| binary little-endian 3DGS PLY | ASCII PLY |
| GraphDeco-style fields | 任意 point cloud PLY 自动转换 |
| `f_dc` base color | 完整 SH 视角相关着色 |
| CPU view-depth sort | GPU radix/tile sort |
| alpha blended splat pass | splat shadow / reflection / physics |
| 一个固定 scene 验收 | 多 3DGS 大场景库 |

## 何时进入下一阶段

| 触发条件 | 下一步 |
|---|---|
| CPU sort 成为瓶颈 | 新增 GPU tile/radix sort REQ |
| `f_dc` 画质不足 | 新增 SH degree 3 shading REQ |
| 需要与 mesh 正确互遮挡 | 新增 depth-aware composite REQ |
| 资产体积再次逼近 800 MB | 新增压缩格式 `.splat` / `.spz` / streaming REQ |
| 需要网页或远程分发 | 新增 runtime compressed format REQ |

## 验收命令建议

| 阶段 | 建议验证 |
|---|---|
| Asset | assets-downloader cache manifest contains `sceneUsage.gaussianSplatUri` |
| Loader | `ninja test_gaussian_splat_ply_loader` |
| Runtime | scene load test for a small fixture scene; Voxel51 cache scene as local smoke |
| Compute | `ninja test_compute_pipeline_smoke` |
| Vulkan | `xvfb-run -a ./src/demos/lxe_editor/lxe_editor ...` 或 lxe_manager smoke |
| Docs | `scripts/notes/serve_site.sh --build` |
