# Debug 复盘

这里收集对本仓库做过的、值得回顾的 debug session：每次都把症状、走过的弯路、最终定位到的根因和修复保留下来，方便后续遇到类似问题时直接对照。

不是每个 bug 都需要复盘——只把那些**症状跟根因之间隔了多层"放大器"或"误导信号"**的、调试代价大的写进来。

## 写作约定

每篇复盘建议包含：

- **摘要**：用 2 段说清楚现象、根因、最终修复
- **时间线**：按时间顺序的关键现象与决策
- **症状演变**：每阶段做了什么、看到什么、排除了什么
- **真正根因**：用一段把机理讲透
- **路上抓到的真实 bug**：那些虽然不是元凶、但是被这次调试顺手修掉的应用层缺陷
- **最终修复**：具体 commit / 文件 / 函数
- **仍开放的问题**：边界情况、长期 TODO
- **工件**：保留下来的"已知好基线" demo、专门的回归测试等
- **教训**：可复用的诊断方法
